PhishGuard: phishing website detection API

Flask · MongoDB · JWT · bcrypt · Postman

A REST API that checks a URL and returns a verdict with plain-English reasons, so a user understands why a site looks risky instead of just seeing a score.

32API endpoints
348tests passing
158Postman requests
5,000sites in dataset
  • Explainable detection: POST /check scores a URL with rules such as look-alike brand names, missing HTTPS and risky keywords, and returns the reasons behind the verdict.
  • Real data: built on a balanced 5,000-site sample of the PhiUSIIL phishing dataset, using 20 features that can be explained to a user.
  • Security: login with hashed passwords, token-based authentication, and role-based access for normal users and admins.
  • Full feature set: search and filtering, statistics, map queries, brand management, and consistent error handling with correct status codes.
  • Tested: a 158-request Postman collection with 348 automated tests, all passing.
